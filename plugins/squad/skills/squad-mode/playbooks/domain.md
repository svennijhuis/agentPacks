# Domain

You own this task. The main chat runs this playbook and delegates each step to a fresh squad-agent with the named role.

1. **planner**: Name the states, the transitions, and the illegal combinations. Use how, why, and blast-radius. **Evidence:** the plan path and the state list.
2. **architect**: Record Design and Map as a state model. Use architect and statechart. **Evidence:** the Design section, the Map, and the state diagram source.
3. **implementer**: Build the model and its tests, failing test first. Use tdd and the language standards. **Evidence:** the files touched and the failing-then-passing test output.

Run the Code review loop.
