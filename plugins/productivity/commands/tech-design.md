# Tech design

Load the `tech-design` skill with the Skill tool by exact name `tech-design`.
Never write `/tech-design` as prose to load it. Then run the mode the person named
(`new`, resume, `grill`, or `ready`).

Type `/tech-design`. Codex: `$tech-design`. Copilot: `/productivity:tech-design`.

- `/tech-design new <name> [types]`
- `/tech-design <name>` resumes that design
- `/tech-design <name> grill [gap]`
- `/tech-design <name> ready`

Do not start a design unless the person typed the command. Do not commit.
