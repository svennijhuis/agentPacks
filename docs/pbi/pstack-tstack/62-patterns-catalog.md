## Problem now

Patterns live in many places: `engineering.md` sections ([`shared/standards/engineering.md`](https://github.com/svennijhuis/agentPacks/blob/34e1dec3535baa1d77cb441ea8c98498dc9b3684/shared/standards/engineering.md)), language standards, Squad agents, and now 11 new PBIs. There is no one list that says: this is the pattern, here is good and bad, here is what enforces it, and do we take it or not.

## Why (plain words)

poteto's point is that a rule only counts when something enforces it ([talk 17:29](https://github.com/svennijhuis/agentPacks/blob/f537b585ee09b291afcd78c64cf5c62e8c93f1d6/docs/pbi/pstack-tstack/sources/poteto-2500prs-transcript.md#L53), [talk 18:18](https://github.com/svennijhuis/agentPacks/blob/f537b585ee09b291afcd78c64cf5c62e8c93f1d6/docs/pbi/pstack-tstack/sources/poteto-2500prs-transcript.md#L55)). A catalog where every row names its enforcement (Reviewer line, check-plan rule, lint or validate check) makes "prose only" visible. A row without enforcement is a skip or a gap, never a silent rule.

## What changes

New file `shared/standards/patterns.md`. Two parts: PA (architecture and code), PB (agent workflow). Every row has the 8 columns below. Agents cite a row by id (`PA05`), the same way they cite engineering.md sections. Rows marked skip stay in the file with the reason, so nobody proposes them again without new facts.
